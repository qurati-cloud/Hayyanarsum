# هيا نرسم — Hayyanarsum

نواة منصة هندسية سعودية: محرر ثنائي الأبعاد بوحدات مترية وشبكة التقاط، طبقات، حفظ محلي، تصدير JSON وDXF وSVG، حصر كميات وتكلفة، وأول قواعد تحقق سعودية موثقة.

شغّل خادمًا محليًا عبر `python3 -m http.server 8000`، والاختبارات عبر `npm test`.

## حدود واضحة

- لا تصدر المنصة شهادة امتثال أو اعتمادًا هندسيًا.
- القواعد المفعلة تخص فقط الفقرة 4-2، البنود 1–6، من اشتراطات إنشاء المباني السكنية المنشورة على بلدي.
- BIM وIFC والتحليل الإنشائي وMEP والمحاكاة غير منفذة بعد.
- أي نتيجة للتنفيذ تحتاج مراجعة مهندس مرخص والجهة المختصة.
